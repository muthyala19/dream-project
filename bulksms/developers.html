Send Your First SMS

Here's a quick example using cURL to send an SMS:

curl -X POST https://api.bulksms.sale/v1/sms/send \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "to": "919876543210",
    "message": "Hello from BulkSMS API!",
    "sender_id": "BULKSM",
    "route": "promotional"
  }'

Authentication

All API requests require authentication using your API key. The API key should be passed in the Authorization header.

Keep your API keys secure. Never commit them to version control systems.

Bearer Token Authentication

Include your API key in the Authorization header as a Bearer token:

Authorization: Bearer sk_live_1234567890abcdef

Getting Your API Key

  1. Log in to your BulkSMS.sale account
  2. Go to Settings → API Keys
  3. Click "Generate New API Key"
  4. Copy the generated key (you'll only see it once!)

API Reference

POST

/v1/sms/send

Send a single SMS message to a phone number

200 400 401
Request Parameters
to (required) - string

Recipient's phone number in international format (e.g., 919876543210)

message (required) - string

The SMS message content (max 160 characters for single SMS)

sender_id - string

6 character alphanumeric sender ID (must be registered with DLT)

route - string

Route type: "promotional" or "transactional" (default: "promotional")

Example Request
{
  "to": "919876543210",
  "message": "Your order #12345 has been shipped. Track here: https://example.com/track/12345",
  "sender_id": "ABCXYZ",
  "route": "transactional"
}
Example Response
{
  "success": true,
  "message_id": "msg_1234567890abcdef",
  "message": "SMS queued for delivery",
  "balance": 950.50
}
POST

/v1/otp/send

Send OTP to a phone number for verification

200 400
Request Parameters
phone (required) - string

Phone number in international format

template_id - string

DLT registered template ID (default template used if not specified)

length - integer

OTP length (4-6 digits, default: 6)

expiry - integer

OTP expiry time in minutes (1-30, default: 10)

Example Request
{
  "phone": "919876543210",
  "template_id": "123456789012345678901234",
  "length": 6,
  "expiry": 5
}
POST

/v1/otp/verify

Verify OTP entered by user

200 400
Request Parameters
phone (required) - string

Phone number that received the OTP

otp (required) - string

OTP entered by the user

Example Response (Success)
{
  "success": true,
  "message": "OTP verified successfully"
}
Example Response (Failure)
{
  "success": false,
  "message": "Invalid OTP",
  "attempts_remaining": 2
}
POST

/v1/whatsapp/send

Send WhatsApp Business message

200 400
Request Parameters
to (required) - string

Recipient's WhatsApp number in international format

template_name (required) - string

Approved WhatsApp template name

parameters - array

Template parameters for dynamic content

Example Request
{
  "to": "919876543210",
  "template_name": "order_confirmation",
  "parameters": [
    {"type": "text", "text": "John Doe"},
    {"type": "text", "text": "OD123456"},
    {"type": "text", "text": "₹2,499"}
  ]
}

API Reference

Example: Sending SMS with Python SDK

from bulksms import BulkSMS

# Initialize client
client = BulkSMS(api_key="your_api_key")

# Send SMS
response = client.sms.send(
    to="919876543210",
    message="Hello from Python SDK!",
    sender_id="BULKSM",
    route="promotional"
)

print(f"Message ID: {response['message_id']}")
print(f"Balance: {response['balance']}")

Webhooks

Receive real-time notifications about message delivery status using webhooks.

Setting Up Webhooks
  1. Log in to your dashboard
  2. Go to Settings → Webhooks
  3. Click "Add Webhook Endpoint"
  4. Enter your callback URL
  5. Select the events you want to receive
  6. Save and verify your endpoint
Available Webhook Events:
  • sms.sent - SMS has been sent
  • sms.delivered - SMS delivered to recipient
  • sms.failed - SMS delivery failed
  • otp.verified - OTP successfully verified
  • balance.low - Account balance is low

Webhook Payload Example

{
  "event": "sms.delivered",
  "data": {
    "message_id": "msg_1234567890abcdef",
    "to": "919876543210",
    "status": "delivered",
    "delivered_at": "2024-01-15T10:30:00Z",
    "network": "Airtel",
    "cost": 0.12
  },
  "timestamp": "2024-01-15T10:30:05Z"
}

Error Codes

Code Message Description
400 Bad Request Invalid request parameters or malformed JSON
401 Unauthorized Invalid or missing API key
403 Forbidden Insufficient permissions or account suspended
429 Too Many Requests Rate limit exceeded
500 Internal Server Error Server error, contact support

Best Practices

🛡️ Security
  • Never expose API keys in client-side code
  • Use environment variables for API keys
  • Implement rate limiting on your end
  • Validate all user input before sending
⚡ Performance
  • Use bulk endpoints for multiple messages
  • Implement async processing for large volumes
  • Cache frequently used data
  • Use webhooks instead of polling
✅ Reliability
  • Implement retry logic for failed requests
  • Monitor delivery reports regularly
  • Keep sufficient balance in your account
  • Test with small batches first
📝 Compliance
  • Obtain proper DLT registrations
  • Get explicit consent from recipients
  • Include unsubscribe instructions
  • Follow TRAI regulations for India
